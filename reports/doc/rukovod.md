 # Техническое руководство: SSG генератор на Node.js

## Что это

Программа, которая превращает Markdown файлы в HTML страницы.

## Структура проекта
proekt/
├── content/ # сюда кладём .md файлы
├── dist/ # сюда программа сохранит .html
└── src/
└── static-gen.js # код генератора

## Как пользоваться

## Шаг 1. Создать Markdown файл
В папке content создайте index.md:

# Моя страница

Привет! Это **мой** сайт.

- Пункт 1
- Пункт 2

## Шаг 2. Запустить генератор
Откройте терминал в корне проекта и выполните:

node src/static-gen.js

## Шаг 3. Посмотреть результат
В папке dist появится index.html. Откройте его в браузере.

## Модификация (творческая часть)
В программу добавлен подсчёт слов в статье с помощью следующей части кода.

const wordCount = md.split(/\s+/).length;

Как это работает:

Текст из .md файла разбивается по пробелам

Полученные части считаются

Результат выводится внизу HTML страницы

Пример вывода: 📊 В этой статье 28 слов
